# hg-intel-site

Coming-soon holding page for **HG Intel** — regulatory & best-practice intelligence for
Australian healthcare. Single self-contained `index.html`, served via GitHub Pages at
**hg-intel.com.au**.

Source of truth for the design lives in the monorepo at
`shared/brand/assets/hg-intel-coming-soon/` (hg-au). This repo is the deploy target only —
copy the updated `index.html` here and push to publish.

- `index.html` — the page (Brand 2 / Colourful Lines; inline CSS, no external assets)
- `CNAME` — custom domain for GitHub Pages (`hg-intel.com.au`)
